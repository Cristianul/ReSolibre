# Architecture index

Use the [project map](docs/architecture/project-map.md) to select a focused
area. [Current architecture](docs/architecture/current-architecture.md)
describes what exists; the [target summary](docs/architecture/target-architecture-summary.md)
routes to intended behavior. [Feature docs](docs/architecture/features/README.md)
hold cross-area implementation detail once it exists.

There is no long aggregate: focused target files are canonical. Complete
reading flows include applicable guidance and fit within 32 KiB. Validate
routing/size changes with `python3 tools/check_docs.py`.
